# Система способностей

Способность — это ScriptableObject `AbilityDefinition` со списком **нод**, которые выполняются сверху вниз как последовательность. Ноды обмениваются данными через **Blackboard** (пер-кастовое хранилище «ключ → значение»). Никакого кода для новой способности писать не нужно — всё собирается в инспекторе.

Готовые примеры: `Assets/Resource/Abilities/` — `Satan/FireBulletAbility` (простой снаряд), `Satan/SatanDoubleShot` (два снаряда с паузой), `Sobaka/WideStrike` (урон по области), `Sobaka/Berserk` (длительный бафф с дрейном HP).

---

## Как создать способность

1. **Create → Psynetika → Ability** в нужной папке (`Assets/Resource/Abilities/<Персонаж>/`).
2. Заполни шапку:
   - `id` — уникальная строка вида `satan.fire_bullet` (для логов/сейвов);
   - `displayName`, `description`, `icon` — для UI;
   - `slot` — `Regular` (обычный скилл) или `Ultimate`;
   - `cooldown` — секунды;
   - `animClip` — клип каста (подменяет `SpellPlaceholder` в аниматоре персонажа; без клипа играет плейсхолдер);
   - `matchDurationToClip` — взять длительность стойки из длины клипа (иначе валидатор предупредит о рассинхроне);
   - `castDuration` / `castMomentNormalized` — длительность стойки каста и момент (0..1), в который реально сработают ноды.
3. Жми **«+ Добавить ноду»** и собирай граф. Заголовок каждой ноды показывает краткое содержание, кнопки: ▲▼ — порядок, ⧉ — дублировать, ✕ — удалить.
4. Смотри на **жёлтые плашки внизу инспектора** — валидатор ловит пустые префабы, несуществующие слои и ключи Blackboard, которые никто не записывает.

### Типовые графы

**Удар по области** (WideStrike):
```
Цели в прямоугольнике   → пишет список целей в 'area.targets'
Расчёт урона от атаки   → пишет число в 'area.damage'
Урон выбранным целям    → читает оба ключа и бьёт
```

**Снаряд** (FireBullet): одна нода «Спавн снаряда» со ссылкой на ProjectileDefinition. Для двойного выстрела: Спавн → Пауза → Спавн.

**Бафф со временем** (Berserk):
```
Тики по таймеру (duration 10, tick 2)
└─ Последовательность
   ├─ Дрейн HP кастера      (Failure при критическом HP → тик пропускается)
   ├─ Счётчик 'berserk.stacks' до 5  (Failure на максимуме → бафы дальше не растут)
   ├─ Бафф стата AttackSpeed +0.1
   └─ Бафф стата Damage +0.1
```
Бафы с `revertOnEnd = true` снимаются автоматически при завершении **или отмене** каста — ноды «сохранить/восстановить стат» не нужны.

## Как создать снаряд

1. **Префаб**: спрайт + `Rigidbody2D` + `Collider2D` (не-триггер). Компонент `ProjectileRuntime` добавится сам при спавне, но можно повесить заранее. Снаряд игнорирует коллайдеры кастера, пролетает союзников насквозь и пулится (не плоди эффекты через OnDestroy).
2. **Create → Psynetika → Projectile Definition**: назначь префаб, `speed`, `lifetime`, `spawnOffset` (X — вдоль взгляда).
3. Заполни три списка нод:
   - `onSpawn` — в момент вылета;
   - `onHit` — при попадании (цель попадает в контекст как `ResolvedTarget` — нода «Урон цели» бьёт именно её);
   - `onExpire` — если время жизни вышло без попадания (например, взрыв по области).
4. В способности добавь ноду «Спавн снаряда» и укажи этот ProjectileDefinition.

Blackboard у снаряда **общий с кастом**, который его выпустил: можно посчитать урон нодой в способности, а применить в `onHit`.

## Каталог нод

| Меню | Что делает | Ключи |
|---|---|---|
| Урон/Урон цели | Бьёт `ResolvedTarget` фиксированным уроном (для onHit снарядов) | — |
| Урон/Урон выбранным целям | Бьёт всех из списка | читает targets + damage |
| Урон/Расчёт урона от атаки | Базовый урон кастера × множитель | пишет damage |
| Урон/Дрейн HP кастера | Снимает % max HP, не убивая (Failure, если нечего снять) | пишет снятое |
| Цели/Цели в прямоугольнике | OverlapBox перед кастером, фильтр по слою и команде | пишет targets |
| Снаряды/Спавн снаряда | Выпускает ProjectileDefinition | — |
| Бафы/Бафф стата | +N к стату; `revertOnEnd` — снять в конце каста | — |
| Эффекты/VFX на кастере | Спавнит префаб эффекта; может жить до конца каста | — |
| Логика/Последовательность | Дети по очереди, Failure ребёнка останавливает | — |
| Логика/Ветвление | condition → onSuccess / onFailure | — |
| Логика/Параллельно | Все дети одновременно, ждёт всех | — |
| Логика/Счётчик (стаки) | +1 к счётчику, Failure на максимуме | пишет счётчик |
| Тайминг/Пауза | Ждёт N секунд | — |
| Тайминг/Тики по таймеру | Выполняет детей каждые N секунд в течение M секунд | — |

## Правила выполнения (важно понимать)

- **Success** — идём дальше. **Failure** — текущая последовательность останавливается (но в «Тиках по таймеру» пропускается только остаток тика). **Cancelled** — каст прерван целиком.
- **Кулдаун** списывается при касте, но **возвращается**, если первая же нода провалилась (каст «не состоялся»).
- **Смерть кастера отменяет** все его активные касты; всё, что зарегистрировало откат (бафы `revertOnEnd`, VFX «до конца каста»), откатывается гарантированно.
- **Blackboard живёт один каст** — счётчики и списки целей не протекают между кастами.
- Поля-ключи имеют кнопку-дропдаун со всеми ключами графа — пользуйся ей вместо ручного набора.

## Как выдать способность

- **Игроку в старте**: Player.prefab → компонент `SpellController` → слоты `satanRegular` / `sobakaRegular` (ультимейты по дизайну пустые — продаются в магазине).
- **В магазин**: ассет `ShopList` (например `Assets/Scripts/interactable/Shop/Shop1.asset`) → добавить элемент: способность, владелец (Satan/Sobaka), слот, цена. Покупка сама назначит её через `Inventory.ChangeAbility`.
- **Врагу**: `EnemyConfig` → список `abilities`; каст — `EnemyAttack.TryCastAbility(...)` из стейта врага.

## Как написать новую ноду

Файл в `Assets/Scripts/Abilities/Core/`, шаблон:

```csharp
using System;
using Cysharp.Threading.Tasks;
using UnityEngine;

[Serializable]
[AddTypeMenu("Категория/Название в меню")]
public class MyNode : AbilityNode
{
    [BlackboardKeyInput] public string inputKey = "some.value";   // если читаешь Blackboard
    [BlackboardKeyOutput] public string outputKey = "my.result";  // если пишешь

    public override UniTask<NodeResult> Execute(AbilityContext ctx)
    {
        // ctx.Owner — кастер, ctx.ResolvedTarget — цель (у снарядов в onHit),
        // ctx.Blackboard — данные каста, ctx.Token — отмена (передавай во все await).
        if (!ctx.Blackboard.TryGet(inputKey, out float value))
            return UniTask.FromResult(NodeResult.Failure);

        ctx.Blackboard.Set(outputKey, value * 2f);

        // Временный эффект? Зарегистрируй откат — он сработает даже при отмене каста:
        // ctx.RegisterCleanup(() => { ...снять эффект... });

        return UniTask.FromResult(NodeResult.Success);
    }
}
```

Чеклист:
1. `[Serializable]` — иначе не сериализуется в ассет.
2. `[AddTypeMenu("Категория/Имя")]` — иначе нода попадёт в «Прочее».
3. Ключи Blackboard — только через `[BlackboardKeyInput]`/`[BlackboardKeyOutput]`: на этом держатся дропдауны и валидация.
4. Асинхронность — через `await UniTask.Delay(..., cancellationToken: ctx.Token)`; никогда не глотай `ctx.Token`.
5. Доступ к кастеру — только через интерфейсы (`IAbilityStatOwner`, `IAbilityHealth`, `IAbilityDamageSource`), не через `GetComponent<PlayerXxx>` — иначе нода не заработает у врагов.
6. Добавь кейс в `AbilityGraphUtility.GetSummary` (заголовок в инспекторе) и, если есть что проверять, в `Validate`.
